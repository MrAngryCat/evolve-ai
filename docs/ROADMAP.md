# Пошаговая дорожная карта — 21 этап (00–20)

Любая стадия запускается только после приёмки предыдущей. Статусы: NOT_STARTED / IN_PROGRESS / BLOCKED / READY_FOR_REVIEW / APPROVED.

## Контрольные точки

- **Gate A (00–04):** воспроизводимая база, память и локальный inference adapter.
- **Gate B (05–08):** проверенные модели и безопасное исследование.
- **Gate C (09–12):** ограниченный цикл программирования, оценки и продолжения задач.
- **Gate D (13–16):** реальные способности: голос, видео и контролируемая работа с ПК.
- **Gate E (17–20):** стабильная сборка с журналом аудита и руководством.

## Критерии перехода

Codex останавливается после текущего этапа и сообщает: (1) новые файлы; (2) фактические тесты и результаты; (3) измерения; (4) что не сделано; (5) риски; (6) инструкции для пользователя; (7) необходимость пересмотра плана.

ChatGPT проверяет отчёт, сопоставляет с критериями и подготавливает один следующий запрос Codex. Владелец принимает этап.

## Блокеры, требующие пересмотра

- Vulkan драйвер не работает с RX 6700 XT или модель даёт некорректные результаты.
- Большая модель загружается, но скорость не подходит для задач.
- SSD/RAM недостаточно для безопасной выгрузки модели.
- Найденный open-source компонент имеет несовместимую лицензию или требует платный API.
- Для реального sandbox требуется неподдерживаемая Windows-функция: использовать тестируемую альтернативу, не отключать защиту.
